The Strata language

One statement per line. Braces define hierarchy. Indentation is for readability. IDs are reusable references; labels are quoted strings.

diagram "My architecture"

app web "Web app"
service platform "Platform" {
  description "Core application services"
  service api "API service"
  database db "PostgreSQL"
}

web -> api : "HTTPS"
api -> db : "SQL"

view overview "System overview" {
  include web, platform
}
view storage "Data access" {
  api -> db : "Read / write"
}
view audit "Audit only" {
  relations only
  api -> db : "Audit record"
}

Types: app, service, database, infrastructure, external.

Views: arrows outside a view are global. Arrows inside a view are local; by default, applicable global arrows are inherited too. Use relations only to opt out of globals. The include list is optional: local endpoints and their parent context are inferred automatically. Explicitly included groups show descendants. With no view declarations, an overview is created automatically.

Tile layout: inside a resource or view, use sizes auto, sizes uniform, or sizes proportional, and compactness 0.6 (0.1–1). Inside views, detail 0.75 sets the initial detail budget (0–1). Zooming or resizing changes how much detail fits; 1 shows everything and 0 shows summary tiles.

Icons: inside an item, add icon "brands/brands_s/stripe_icon.svg". Paths are relative to icons/. Referenced icons are embedded in offline HTML; offline edits can reuse those embedded paths.

Dashed connections: append dashed after the optional label: api -> queue : "Publish" dashed or api -> queue dashed. Connections are solid by default.

Comments: use #. Forward references are supported. Strings use JSON escaping. IDs start with a letter or underscore and can contain digits, dots, hyphens, or underscores.

Editing: preview updates after 300 ms. Invalid source keeps the last valid preview. Tab inserts two spaces; ⌘/Ctrl+Enter updates immediately.

Navigation: select resources for details; double-click groups to collapse. Space toggles a focused group. Collapse only changes the view, never the source.

Persistence: the last valid source is saved in this browser. Export .strata to keep it in Git. Import accepts Strata or compatible JSON; SVG exports the current perspective. Offline HTML embeds the full editor, model, styles, and renderer in a single file; it opens directly from disk without a server or internet connection. Export it again to save edits.

Limits: 300 resources, 1,000 total global/perspective relationships, 30 views, 12 hierarchy levels, 1 MB source.
